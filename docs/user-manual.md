# 使用说明书

> 版本：1.0 | 适用固件：AutoIrrigation v1.0+

## 1. 适用人群

- 具备基本 Arduino / ESP32 烧录经验的用户
- 需要在室内多盆植物自动定量浇水的场景

无需编程即可通过 Web 界面完成日常配置；进阶标定与故障排查可使用串口 CLI。

---

## 2. 包装与组件

开箱后请核对 [bom.md](bom.md) 清单：

- ESP32-C3 开发板 × 1
- 电容式土壤湿度传感器 × 2
- YF-S201 流量计 × 1
- 12 V 微型水泵 × 1
- 5 V 继电器模块 × 1
- 12 V 电源、软管、杜邦线

---

## 3. 硬件组装

### 3.1 组装步骤

1. **固定 ESP32**：置于干燥处，避免溅水
2. **连接湿度传感器**：Zone 0 → GPIO0，Zone 1 → GPIO1（VCC 3.3 V，GND 共地）
3. **安装流量计**：按箭头方向串入水路，见 [wiring.md](wiring.md)
4. **连接水泵与继电器**：12 V 经继电器低侧开关控制，GPIO3 → 继电器 IN
5. **共地**：12 V 电源 GND 与 ESP32 GND 必须相连
6. **插入湿度探头**：埋入各盆根部区域，电路板留在外面

### 3.2 首次上电前检查

- [ ] 无短路、水泵未浸入无水源状态长时间空转
- [ ] 流量计方向正确
- [ ] 所有 GND 共地

## 4. 首次配置

### 4.1 烧录固件

```bash
pio run -e esp32-c3-irrigation -t upload
pio device monitor -b 115200
```

串口应显示：

```
AutoIrrigation v1.0
Board: ESP32-C3-Irrigation
WiFi: disabled
```

### 4.2 WiFi 配网

**方式 A — 串口 CLI**

```
wifi ssid 你的WiFi名称
wifi pass 你的密码
wifi on
save
```

重启后串口会打印 IP 地址，例如 `WiFi connected: 192.168.1.100`。

**方式 B — Web 配网**

若固件启用了 AP 回退，可连接热点 `ESP32-IRRIGATION`（密码见 `config.h`），浏览器打开 `http://192.168.4.1` 配置。

### 4.3 打开 Web 界面

浏览器访问 `http://<设备IP>/`，可看到：

- 各分区湿度与状态
- 手动浇水按钮
- 阈值与体积设置
- WiFi 配置

## 5. 日常使用

### 5.1 阈值自动浇水

1. 在 Web「分区设置」中设置 **湿度下限**（如 30%）和 **上限**（如 60%）
2. 设置 **单次浇水量**（如 100 mL）
3. 开启 **自动模式**
4. 系统每 5 秒检测湿度；低于下限时自动浇水，达到上限或目标体积后停止

### 5.2 定时浇水

1. 设置 **定时时间**（如 08:00）
2. 开启 **定时模式**
3. 到点按设定体积浇水（与阈值模式可并存，各自独立触发）

### 5.3 手动浇水

- **Web**：选择分区，输入 mL，点击「浇水」
- **CLI**：`water 0 100`（Zone 0 浇 100 mL）

### 5.4 多盆顺序灌溉

当前版本为 **单泵顺序** 灌溉：

1. 系统一次只浇一个分区
2. 请将出水口对准当前正在浇水的花盆
3. 下一分区自动排队执行

## 6. 传感器标定（推荐）

出厂默认校准可能不准，建议：

1. 干燥土：`cal dry 0`（Zone 0）
2. 浇透后：`cal wet 0`
3. `save`

Zone 1 将 `0` 改为 `1` 重复。标定后 Web 湿度百分比更准确。

---

## 7. 状态指示灯（RGB LED）

| 颜色/模式 | 含义 |
|-----------|------|
| 绿色常亮 | 空闲，系统正常 |
| 蓝色慢闪 | 正在浇水 |
| 黄色 | 检查 / 排队中 |
| 红色 | 故障锁定（干转、超时等） |

## 8. 日常维护

| 项目 | 周期 | 操作 |
|------|------|------|
| 湿度探头 | 每月 | 擦拭表面盐渍，检查是否松动 |
| 流量计 | 每季 | 拆洗叶轮，防止杂质卡死 |
| 水泵 | 每季 | 检查噪音与流量，清理进水口 |
| 软管 | 按需 | 检查老化、漏水 |
| 储水桶 | 每周 | 补充清水，避免空抽 |

---

## 9. 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| Web 打不开 | WiFi 未连或未开 | 串口 `wifi on`，确认 IP |
| 湿度始终 0% 或 100% | 未标定或探头损坏 | 执行 `cal dry/wet`，更换探头 |
| 不自动浇水 | 自动模式关闭或日限额满 | Web 检查开关与 `daily_ml` |
| 泵不转 | 继电器/12 V 供电 | 查接线，`pump on` 测试 |
| 报 DRY_RUN | 无水或流量计故障 | 加水，检查流量计与 `ppl` 标定 |
| 报 TIMEOUT | 单次超时 | 增大 `max_run_sec` 或检查堵塞 |
| 浇水量不准 | 脉冲系数不对 | 按 [development.md](development.md) 重标定 |
| 重启后配置丢失 | 未 save | 修改后 CLI `save` 或 Web 保存 |

### 9.1 恢复默认

串口执行（若固件支持）：

```
# 清除 NVS 需重新烧录或扩展 CLI factory 命令
stop
```

联系开发者或重新烧录可恢复出厂默认。

---

## 10. 安全注意事项

1. **电气**：12 V 与 3.3 V 线路分开，**必须共地**；户外使用防水盒
2. **防水**：ESP32 与继电器勿长期溅水；湿度模块电路板不可浸没
3. **溢水**：花盆需有排水孔；储水桶水位不宜过高以免虹吸
4. **空转**：禁止水泵长时间无水运行；系统有干转保护但仍需尽快加水
5. **儿童与宠物**：水泵与 12 V 电源应放在接触不到的位置
