# 使用说明书

> 版本：2.1 | 适用固件：AutoIrrigation v2.1+

## 1. 适用人群

- 具备基本 Arduino / ESP32 烧录经验的用户
- 需要在室内多盆植物自动定量浇水的场景

无需编程即可通过 Web 界面完成日常配置；进阶标定与故障排查可使用串口 CLI。

---

## 2. 包装与组件

开箱后请核对 [bom.md](bom.md) 清单：

- **ESP32-S3** 开发板 × 1（I2C GPIO8/9，0.96" SSD1306 状态屏）
- I2C 扩展模块：ADS1115 ×3 + PCA9555 ×1
- 电容式土壤湿度传感器 × 1–10（按盆数）
- YF-S201 流量计 × 1
- 12 V 微型水泵 × 1
- 5 V 继电器模块 ×（1 水泵 + N 阀）
- 12 V 电磁阀 × N
- 12 V 电源、软管、杜邦线 / I2C 排线

## 3. 硬件组装

### 3.1 组装步骤

1. **固定 MCU**：置于干燥处，I2C 四线（SDA/SCL/VCC/GND）接扩展板
2. **扩展板**：三块 ADS1115 地址设为 0x48/0x49/0x4A，PCA9555 为 0x20（见 [bom.md](bom.md)）
3. **连接湿度传感器**：每盆探头 AO → 对应 ADS1115 通道（盆 0–9 映射见 [wiring.md](wiring.md)）
4. **连接电磁阀**：每路阀继电器 IN → PCA9555 P0–P9
5. **安装流量计**：按箭头串在泵后；信号接 **GPIO5**
6. **连接水泵继电器**：12 V 经继电器控制，MCU **GPIO4**
7. **共地**：12 V 电源 GND 与 ESP32 GND 必须相连
8. **插入湿度探头**：埋入各盆根部，电路板留在外面
9. **S3 状态屏**：0.96" SSD1306 四针接 I2C（SDA=GPIO8，SCL=GPIO9，3.3V/GND）。第一行显示时间；还没对时会显示「请连手机蓝牙对时」
10. **两个自复按钮**：动作键 GPIO6、急停键 GPIO7，另一端都接 GND。短按动作键＝检测并给偏干的盆排队浇水；长按约 0.8 秒＝全部盆切换自动/手动；急停键按下即停泵关阀并锁定

### 3.2 首次上电前检查

- [ ] I2C 扩展板地址跳线正确（ADS1115 ×3 + PCA9555）
- [ ] 无短路、水泵未在无水状态长时间空转
- [ ] 流量计方向正确
- [ ] 所有 GND 共地

## 4. 首次配置

### 4.1 烧录固件

```bash
pio run -e esp32-s3-irrigation -t upload
pio device monitor -b 115200
```

串口应显示：

```
AutoIrrigation v2.1
Board: ESP32-S3-Irrigation
Zones: 2 (max 10 valves, I2C expanders)
WiFi: enabled
AP: 192.168.4.1 (hybrid)
WiFi connecting to OneMore...
WiFi connected: 192.168.x.x
```

默认连接 **`OneMore`**（与 TempControl 相同），同时开启热点 **`ESP32-IRRIGATION`**（混合模式）。局域网 IP 与 AP `192.168.4.1` 均可访问 Web。

### 4.2 WiFi 配网（可选覆盖默认）

**方式 A — 串口 CLI**

```
wifi ssid 你的WiFi名称
wifi pass 你的密码
wifi on
save
```

重启后串口会打印 IP 地址，例如 `WiFi connected: 192.168.1.100`。

**方式 B — Web 配网**

若固件启用了 AP 回退，可连接热点 `ESP32-IRRIGATION`（密码见 `config.h`），浏览器打开 `http://192.168.4.1` 配置。

### 4.3 打开 Web 界面

浏览器访问 `http://<设备IP>/`，可：

- 查看实时湿度、泵/阀状态
- **编辑并保存** 每盆阈值、体积、定时、校准、名称
- 调整系统参数（盆数、ppl、日限额等）
- **测试控制台**（等效串口 CLI，无需串口）：
  - 队列浇水、急停、停止/清故障
  - 泵 ON/OFF、开阀/阀全关
  - 标定干/湿、立即采样湿度
  - 读流量、流量清零、I2C 扫描
  - 单区/全部 自动模式开关
  - 「仅应用盆数」快速改激活分区数
- 配置 WiFi

日常浇水也可以不打开网页，用安卓 App（§4.4）。

## 使用 Web 界面（家庭首页）

- 浏览器打开 `http://<设备IP>/`：查看各盆湿度（偏干红/正常绿/偏湿蓝）、今日已浇总量、正在浇哪盆
- 点击盆卡片展开：开关自动浇水、一键浇水（水量可临时调整）
- 自动浇水时段默认 17:00-21:00（避免夏季中午浇水伤植物），可在调试页修改
- 出现故障横幅时，排除原因后点"恢复运行"
- `http://<设备IP>/dev` 为调试页（开发者使用：标定、参数、测试）

### 4.4 安卓 App（蓝牙）

1. 用 Android Studio 打开仓库里的 `android/` 目录，装到手机（Android 8 及以上）
2. 灌溉器上电后蓝牙广播名是 **Langua**。打开 App「蓝瓜智控」会自动搜索并连接一次。允许蓝牙和位置权限。vivo 必须打开系统定位，否则扫不到旁边的设备
3. 底部三个标签：首页看湿度和浇水，设置里连接设备和改湿度上下限，调试里标定、开关泵阀
4. 首页顶部是四盆一行的实拍总览，浇水时对应盆会有水滴动画；下面是检测并浇水、每盆自动和水量、最近浇水记录。设置：自动时段、每盆定时和阈值、别名和实拍图（只存在这台手机）、日限额、盆数、WiFi。调试：标定、泵阀、流量计、排气
5. 每次蓝牙连上，手机会把当前时间发给灌溉器。没有 WiFi 时，定时浇水靠这次对时
6. 配网可以在 App 设置页完成，网页 `/dev` 仍然可用

手机和灌溉器不需要连同一个 WiFi，靠近设备即可。

## 5. 日常使用

### 5.1 阈值自动浇水

1. 在 Web「分区设置」中设置 **湿度下限**（如 30%）和 **上限**（如 60%）
2. 设置 **单次浇水量**（如 100 mL）
3. 开启 **自动模式**
4. 系统每 5 秒检测湿度；低于下限时自动浇水，达到上限或目标体积后停止

### 5.2 定时浇水

1. 设置 **定时时间**（如 08:00）
2. 开启 **定时模式**
3. 到点按设定体积浇水（与阈值模式可并存，各自独立触发）
4. 没有 WiFi 时，用手机打开「蓝瓜智控」连上蓝牙，会把手机时间写进灌溉器。定时按东八区计算

### 5.3 手动浇水

- **Web**：选择分区，输入 mL，点击「浇水」
- **CLI**：`water 0 100`（Zone 0 浇 100 mL）

### 5.4 多盆灌溉（v2）

每盆固定接一路电磁阀和湿度探头，**无需移动水管**：

1. 系统按队列依次：开阀 → 开泵 → 定量 → 关阀
2. 单盆使用时 CLI 执行 `set zones 1`，只启用 Zone 0
3. 增加花盆：接新阀、新探头到扩展板，`set zones N`（1–10）后 `save`

## 6. 传感器标定（推荐）

出厂默认校准可能不准，建议：

1. 干燥土：`cal dry 0`（Zone 0）
2. 浇透后：`cal wet 0`
3. `save`

Zone 1 将 `0` 改为 `1` 重复。标定后 Web 湿度百分比更准确。

### 6.2 各盆浇水量标定（水管长短不一）

系统只有 **1 个流量计**（装在泵后），测的是主路总流量。从分水器到各盆的管子长度不同时，**同一 mL 设定，进土量会不一样**——长管盆偏少，短管盆可能偏多。

**做法：给每盆单独设 `volume_ml`，不要所有盆用同一个数。**

1. 首次通水后排气（Web 测试泵/阀，或 CLI `valve 0` + `pump on` 几秒）
2. 盆 0（长管）：`water 0 300`，用量杯看实际进盆多少毫升
3. 想要每次进盆 100 mL → 按比例改 Web 里盆 0 的「单次 ml」  
   例：300 mL 设定只进了 80 mL → 设为 `100 × 300 ÷ 80 ≈ 375`
4. 盆 1 重复（短管通常设定值更小）
5. Web **保存设置** 或 CLI `save`

**安装建议（提高精度）：**

| 项目 | 建议 |
|------|------|
| 电磁阀 | **12 V 两通常闭**，每盆 1 个（**不要三通**） |
| 流量计 | 泵 → **直管** → 流量计 → **直管** → 分水器 |
| 止回阀 | 每个阀后面 1 个 |
| 分水器 | 尽量靠近流量计 |

详见 [wiring.md](wiring.md)、[bom.md](bom.md)。

## 7. 状态指示灯（GPIO8）

板载 LED，**低电平亮**（0.42 OLED 小板）。

| 状态 | 表现 |
|------|------|
| 空闲正常 | 灭 |
| 浇水中 | 闪烁 |
| 故障锁定 | 常亮 |

## 8. 日常维护

| 项目 | 周期 | 操作 |
|------|------|------|
| 湿度探头 | 每月 | 擦拭表面盐渍，检查是否松动 |
| 流量计 | 每季 | 拆洗叶轮，防止杂质卡死 |
| 水泵 | 每季 | 检查噪音与流量，清理进水口 |
| 软管 | 按需 | 检查老化、漏水 |
| 储水桶 | 每周 | 补充清水，避免空抽 |

## 9. 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| Web 打不开 | WiFi 未连或未开 | 串口 `wifi on`，确认 IP |
| 湿度始终 0% 或 100% | 未标定、探头损坏或 ADS1115 未接 | 查 I2C 接线与地址，`cal dry/wet`，更换探头 |
| 不自动浇水 | 自动模式关闭或日限额满 | Web 检查开关与 `daily_ml` |
| 泵不转 | 继电器/12 V 供电 | 查接线，`pump on` 测试 |
| 报 DRY_RUN | 无水或流量计故障 | 加水，检查流量计与 `ppl` 标定 |
| 报 TIMEOUT | 单次超时 | 增大 `max_run_sec` 或检查堵塞 |
| 阀不动作 | PCA9555 或继电器 | 串口 WARN 检查，`valve 0` 测试 |
| 浇水量不准 | `ppl` 未标定或各盆支管长度不同 | 先标定 `ppl`，再 **每盆单独** 标 `volume_ml`（见 §6.2） |
| 长管盆浇得少 | 死体积大 | 增大该盆 `volume_ml` 或缩短支管、加止回阀 |
| 重启后配置丢失 | 未 save | 修改后 CLI `save` 或 Web 保存 |

### 9.1 恢复默认

串口执行（若固件支持）：

```
# 清除 NVS 需重新烧录或扩展 CLI factory 命令
stop
```

联系开发者或重新烧录可恢复出厂默认。

## 10. 安全注意事项

1. **电气**：12 V 与 3.3 V 线路分开，**必须共地**；户外使用防水盒
2. **防水**：ESP32 与继电器勿长期溅水；湿度模块电路板不可浸没
3. **溢水**：花盆需有排水孔；储水桶水位不宜过高以免虹吸
4. **空转**：禁止水泵长时间无水运行；系统有干转保护但仍需尽快加水
5. **儿童与宠物**：水泵与 12 V 电源应放在接触不到的位置
