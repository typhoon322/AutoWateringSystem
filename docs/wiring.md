## 引脚定义

引脚在 [`include/boards/board_c3.h`](../include/boards/board_c3.h) 中定义。

| 功能 | GPIO | 说明 |
|------|------|------|
| 湿度 Zone 0 | GPIO0 | ADC，接电容湿度 AO |
| 湿度 Zone 1 | GPIO1 | ADC |
| 水泵继电器 | GPIO3 | 数字输出 |
| 流量计脉冲 | GPIO5 | 中断输入，模块 SIG |
| RGB LED | GPIO8 | 板载，无需外接 |

> **注意**：ESP32-C3 的 GPIO11–17 通常接 Flash，**不可使用**。

## 引脚连接

### 电容式土壤湿度（×2）

| 湿度模块 | ESP32-C3 |
|----------|----------|
| VCC | 3.3 V |
| GND | GND |
| AO | GPIO0（Zone 0）或 GPIO1（Zone 1） |

- 探头插入盆土，**不要**让电路板长期浸水
- 同一批次传感器 AO 范围可能不同，需通过 CLI `cal` 命令校准

### YF-S201 流量计

| 流量计 | 连接 |
|--------|------|
| 红色 (+) | 12 V（与泵同源） |
| 黑色 (-) | GND（与 ESP32 共地） |
| 黄色 (SIG) | GPIO5 |

```
水流方向 ──→  [泵] ──→ [流量计 IN] ──→ [流量计 OUT] ──→ 出水口
```

### 继电器 + 水泵（低侧开关）

```
12V+ ──→ [水泵 +] ──→ [水泵 -] ──→ [继电器 COM]
                                      │
12V+ ──→ [流量计]（并联）
                                      │
                              [继电器 NO] ──→ GND
```

继电器模块：

| 继电器模块 | ESP32-C3 |
|------------|----------|
| VCC | 5 V（USB 或降压模块） |
| GND | GND |
| IN | GPIO3 |

> 若模块为 **低电平触发**，固件默认 `PUMP_ACTIVE_HIGH=1` 表示 GPIO 高电平吸合；若你的模块相反，在 `board_c3.h` 改为 `0`。

### 电源与共地

```
        ┌─────────────┐
12V ────┤ 适配器      ├──→ 水泵、流量计
        └──────┬──────┘
               GND ────────────── ESP32 GND（必须连接）
USB 5V ───────────────────────── ESP32 5V / USB
```

## 水路示意

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│  水源桶   │───→│  水泵     │───→│ YF-S201  │───→ 出水 → 花盆
└──────────┘    └──────────┘    └──────────┘
                      ↑
                 继电器控制
```

多分区时：顺序将出水口移至目标花盆，或后续加装电磁阀。

## 烧录

```bash
pio run -e esp32-c3-irrigation -t upload
pio device monitor -b 115200
```

## 上电检查

1. 不上水，仅上电：串口应打印 `Board: ESP32-C3-Irrigation`
2. `status` 命令应显示两路湿度 ADC 原始值或百分比
3. `pump on` 应听到继电器吸合（**勿长时间空转**）
4. 通水后 `flow` 命令应显示脉冲增加
