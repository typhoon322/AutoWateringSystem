# 接线说明 — I2C 扩展板 + 单泵多阀

## 架构

**一块 I2C 扩展子板** 接所有湿度探头与电磁阀；MCU 只接 I2C、泵、流量计、LED。

| 器件 | I2C 地址 | 用途 |
|------|----------|------|
| ADS1115 #0 | 0x48 | 湿度 AIN0–3 → 盆 0–3 |
| ADS1115 #1 | 0x49 | 湿度 AIN0–3 → 盆 4–7 |
| ADS1115 #2 | 0x4A | 湿度 AIN0–1 → 盆 8–9 |
| PCA9555 | 0x20 | 阀继电器 P0–P9 → 盆 0–9 |
| OLED 状态屏 | 0x3C | 0.96" SSD1306，与扩展板共用 I2C |

布局定义见 [`include/boards/board_io_map.h`](../include/boards/board_io_map.h)。

## MCU 直连（`board_s3.h`）

| 功能 | GPIO |
|------|------|
| I2C SDA / SCL | 8 / 9（扩展板 + 0.96" SSD1306） |
| 水泵继电器 | 4 |
| 流量计脉冲 | 5 |
| 状态 LED | 48 |
| 动作键（自复） | 6（短按检测浇水，长按切换自动/手动） |
| 急停键（自复） | 7（按下即急停） |

## 电容式土壤湿度

每盆一路接 ADS1115 单端输入（3.3 V 供电，AO → ADS1115 AINx，GND 共地）。电路板勿长期浸水。

## 水路总览（推荐接法）

```
[水源] → [泵] → [直管 15–20cm] → [YF-S201] → [直管 15–20cm] → [分水器]
                                                                  ├─ [阀0] → [止回阀] → 长/短支管 → 盆0
                                                                  ├─ [阀1] → [止回阀] → 支管 → 盆1
                                                                  └─ … 最多 10 路
         ↑ MCU GPIO 继电器                                              ↑ PCA9555 驱动
```

### 流量计安装要点

| 要点 | 说明 |
|------|------|
| **位置** | **泵后、分水器前**（所有水必经过表） |
| **勿装** | 某一盆支管上（只能准一路） |
| **直管段** | 表前表后各 **15–20 cm** 直管，减少弯头涡流 |
| **方向** | 按壳体箭头，保证满管排气 |
| **排气** | 首次或久置后：`valve <n>` + `pump on` 排空气再定量 |

固件在 **开泵时清零计数**（阀已开并等待 500 ms 后），测的是主路总流量，含该路支管「死体积」。

### 电磁阀（每路）

- 型号：**12 V DC 两通常闭（NC）**，**不要三通阀**
- 驱动：PCA9555 Px → **3.3V 逻辑兼容继电器（低电平触发）** / MOSFET → 12 V 阀
- 阀后建议 **止回阀**，避免停泵后支管水倒流、换盆时体积不准
- 阀与泵 **必须共地**

### 继电器接线（⚠️ 2026-08-18 实测踩坑后定稿）

**选型**：必须 **3.3V 逻辑兼容 + 低电平触发**（如 SRD-03VDC），见 [bom.md 选型红线](bom.md)。
**5V/12V 线圈光耦模块（SRD-05/12VDC）配 3.3V MCU 会"灯亮但吸合无力/误吸合"，不可用。**

```
12V+ ──┬── 继电器 DC+/VCC（仅 3.3V 模块例外：VCC 接 3.3V/5V 按线圈规格）
       └── 继电器 COM（触点输入）
12V- ── DC-/GND（共地）
MCU GPIO4（泵）/ PCA9555 Px（阀）── IN
继电器 NO ── 泵/阀 正极
泵/阀 负极 ── 12V-
继电器 NC ── 悬空不接（接 GND = 12V 轨短路，曾烧毁电源板）
```

固件约定（与低电平触发模块匹配，勿改）：**开 = 引脚输出 0V（吸合）；关 = 引脚高阻（释放）**。

### 管长不一致时的水量

单表方案下，流量计读数 = 经过主路的水量，**不等于**各盆进土量完全一致：

- 阀 → 盆 的支管越长，同样 `volume_ml` 设定，进土越少
- **处理**：每盆单独标定 `volume_ml`（见 [user-manual.md §6.2](user-manual.md) 与 [development.md §6.3](development.md)）

分水器尽量 **靠近流量计**，缩小共用段死体积。

## 电源

```
12V 3A ──→ 泵、流量计、各电磁阀
  │
  GND ──共地── ESP32 GND
USB ──→ ESP32（开发）
或 12V ──→ 降压 5V/1A ──→ ESP32 + 继电器 VCC
```

## 烧录

```bash
pio run -e esp32-s3-irrigation -t upload
pio device monitor -b 115200
```

## 上电检查

1. 串口打印 `AutoIrrigation v2.1` 与 `Zones: N (max 10 valves, I2C expanders)`
2. 无 ADS1115/PCA9555 时会 WARN，接好扩展板后重启
3. `status` 显示各盆湿度
4. `valve 0` / `valve off` 调试阀
5. 通水后排气，再 `water 0 50` 定量测试
