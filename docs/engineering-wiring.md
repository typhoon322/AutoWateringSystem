# 工程布线方案（v1.0 定稿）

> 日期：2026-08-18 | 状态：定稿待实施 | 关联：[wiring.md](wiring.md)、[bom.md](bom.md)
> 当前规模：4 盆起步，预留 10 盆扩展 | 控制盒离花盆 1-3 m

## 1. 系统拓扑总览（两区制）

```
┌──────────── 控制区（主板附近，全部固定）────────────────────┐
│                                                           │
│  [12V 适配器]→[双输出电源板 5V/12V]                         │
│      ├── 12V+ → [12V+ 汇流排] → 6连装继电器板 COM（母排）   │
│      ├── 5V+  → [5V 汇流排]  → ESP32 5V、AMS1117-3.3 IN    │
│      │                             └→ [3.3V 汇流排]→ 继电器板 VCC + 湿度计 VCC │
│      └── GND  → [GND 汇流排] → 全部设备地（共地）            │
│                                                           │
│  [泵]→[YF-S201 流量计]→[分水器]→[阀×4]→[止回阀×4]           │
│  ESP32(GPIO4→泵IN, GPIO5→流量计) + 扩展板(PCA9555→阀IN, ADS1115→湿度AO) │
└──────────┬──────────────────────────────┬──────────────────┘
           │ 水管（阀→花盆喷头）             │ 湿度计线束（3线×N，网线）
           ▼                              ▼
     [花盆区：仅 水管头 + 土壤湿度计]
```

## 2. 供电设计

电源：12V 适配器 → 双输出电源板（12V / 5V 两路，共地）。**无独立降压模块**（5V 由电源板提供）。

### 2.1 汇流排分配

| 汇流排 | 进 | 出（4 盆） | 10 盆 | 电流 |
|---|---|---|---|---|
| **12V+** | 电源板 12V+ | 继电器板 COM（母排短接） | +扩展阀 | 峰值 ~2.5A |
| **5V** | 电源板 5V+ | ESP32 5V、AMS1117-3.3 IN | 不变 | ~0.5A |
| **3.3V** | AMS1117-3.3 OUT | 继电器板 VCC、湿度计 VCC（桥接） | +第2块继电器板 | ~0.3A（多路同时 ~0.4A） |
| **GND** | 电源板 GND | ESP32/继电器板/泵/阀×4/流量计/湿度计/AMS1117 | +阀×6 | — |

> ⚠️ 5V 路电流确认：ESP32+WiFi ~0.3A + AMS1117 输入 ~0.4A ≈ 0.7A，电源板 5V 路需 ≥1A（看电源板标牌）。

### 2.2 3.3V 供电（独立，不抽 ESP32 3V3）

```
电源板 5V+ → [AMS1117-3.3 模块] → [3.3V 汇流排] → 继电器板 VCC（3.3V 线圈 SRD-03VDC）
                                              └→ 湿度计 VCC（3.3V 供电，AO 满量程 ~3.2V）
```

- 电流预算：泵+1 阀同时 ~200mA（系统排队逻辑），AMS1117 800mA 余量充足
- **勿从 ESP32 3V3 引脚直抽继电器线圈电流**（WiFi 峰值 + 线圈会拉垮 3.3V）

## 3. 继电器接线（6 连装板）

- **COM 全部短接 → 12V+ 汇流排**（标准做法，触点互不影响；系统同时最多泵+1阀，母排电流安全）
- **NC 悬空不接**（接 GND = 12V 短路，2026-08-18 曾烧毁电源板 470Ω）
- NO → 泵/阀正极，负载负极 → GND 汇流排
- IN ← 信号端子排（泵=GPIO4，阀=PCA9555 P0-P9）
- VCC ← 3.3V 汇流排（3.3V 线圈版）
- 板内电源端子确认：母排 or 每路独立（决定 3.3V 排位数）

## 4. 湿度计线束（到花盆的唯一电气）

- **3.3V 供电**（AO 满量程 ~3.2V，直接进 ADS1115，无需分压）
- 每盆 3 线：VCC(3.3V)、AO、GND
- **网线（8 芯双绞），每根带 2 盆**；AO 用双绞对（信号+GND 绞一起），1-3m 无干扰
- 两端热缩管标签（盆号+线色），防 10 盆时认错
- 控制盒出线口用防水格兰头（PG7）+ 波纹管

## 5. 信号端子排（一对一，插拔式）

| 信号 | 4 盆 | 10 盆 |
|---|---|---|
| 泵 IN（GPIO4→继电器） | 1 | 1 |
| 阀 IN（PCA9555 P0-P3→继电器） | 4 | 10 |
| 流量计信号（GPIO5） | 1 | 1 |
| 湿度计 AO（ADS1115 AIN0-3） | 4 | 10 |
| 动作键（GPIO6，自复，另一端 GND） | 1 | 1 |
| 急停键（GPIO7，自复，另一端 GND） | 1 | 1 |
| **合计** | **12 位** | **24 位** |

（湿度计 VCC/GND 走 3.3V/GND 汇流排，桥接 1 位即可，不进信号排。）

```
泵 → 直管15-20cm → YF-S201 → 直管15-20cm → 分水器 → 阀1→止回阀1→花盆1 …
```

## 8. 施工顺序与自检

1. 电源区：电源板固定 → 汇流排接线 → **万用表测 12V+ 对 GND 无短路**（NC 教训）→ 测 5V
2. AMS1117 → 测 3.3V
3. 控制区：ESP32+扩展板 → I2C 扫描（0x20/0x48/0x49/0x4A/**0x3C 屏**）
   - 0.96" SSD1306：VCC=3.3V，GND，SDA=GPIO8，SCL=GPIO9
   - 动作键 GPIO6、急停键 GPIO7：自复开关，另一端接 GND
4. 执行区：继电器板逐路 IN 短接 GND 试吸合 → 接信号排 → Web 全测
5. 湿度计线束 → Web 看 ADC/有效性 → **重新标定 cal_dry/cal_wet**（3.3V 供电值变化）
6. 水管接好 → 空跑排气 → 入盆

## 9. 4→10 盆扩展（零代码改动）

| 项 | 动作 |
|---|---|
| 盆数 | Web 系统参数 `zone_count=10`（NVS 保存） |
| 2、3 号 ADS1115 | 焊扩展板，ADDR 跳 0x49/0x4A（自动探测） |
| 阀 5-10 | PCA9555 P4-P9 → 第 2 块 6 连装继电器板 |
| 湿度计 5-10 | 对应 AIN + 网线 +1 |
| 每盆标定 | cal dry/wet + set vol（管长不同逐盆标） |

## 10. 已知注意点

- 3.3V 电流：测试勿同时开多路继电器（固件排队逻辑已限制，实测按泵+1阀节奏）
- ADS1115 PGA 检查：3.3V 供电下 AO 满量程 ~3.2V，确认单端增益配置不浪费分辨率（联调时核对 ads1115.cpp）
- 12V 与 3.3V/信号线分两侧线槽走，防电源噪声串入模拟信号
