# 成品防护与电气安全施工清单

> 日期：2026-08-22 | 版本：v1.0 | 关联：[engineering-wiring.md](engineering-wiring.md)、[bom.md](bom.md)
> 用途：防水盒装机时逐项对照施工。🚨 教训来源：2026-08-18 NC 误接 GND 致 12V 短路、470Ω 烧毁；3.3V MCU 与 5V/12V 线圈继电器不兼容。

## 1. 感性负载保护（续流二极管）

| 负载 | 位置 | 型号 | 接法 |
|---|---|---|---|
| 泵电机 | **泵两端**（不是继电器内部） | 1N5408 或 3A 肖特基 | 阴极 → 12V+，阳极 → 泵负极 |
| 12V 电磁阀 | **阀线圈两端** | 1N4007 | 阴极 → 12V+，阳极 → 阀另一端 |
| 继电器模块内部线圈 | 模块 PCB 自带 | 确认即可 | 无则按上法补 |

> 二极管必须紧贴负载端安装（线尽量短），保护泵/阀断电瞬间反电动势，同时减少触点拉弧。

## 2. 电源防护（防"烧板子"级事故）

| 项 | 做法 | 状态 |
|---|---|---|
| **12V 输入保险丝** | 3A/5A 慢熔保险丝座，串在电源板 12V+ 之后（尽量靠近输入端） | 🔴 必做 |
| 5V 输出保险丝 | 1A 自恢复保险丝（PTC），串在电源板 5V+ 输出 | 🟠 建议 |
| 反接保护 | 12V 输入串肖特基二极管（或 P-MOS 防反接电路） | 🟠 建议 |
| 保险丝规格 | 慢熔（T 型），额定 > 正常工作电流（泵+1阀 ≈2.5A 峰值） | — |

> 目的：任何短路（如 NC 误接 GND）→ 保险丝熔断，而不是烧板载电阻/电源板。

## 3. 防水盒施工

| 项 | 做法 | 状态 |
|---|---|---|
| 出线格兰头 | 每个出线口一个 PG7/PG9：12V 电源、湿度计线束、屏幕排线；水管进出口用穿板接头（勿直接塞孔） | 🔴 必做 |
| **防凝露** | PCB 刷**三防漆** + 盒内放**硅胶干燥剂** + 装**防水透气阀**（平衡气压、减凝露） | 🔴 必做 |
| 散热 | 功耗估算 3-5W（电源板+降压+继电器吸合）；铝盒或盒壁散热片；发热件与 PCB 分装 | 🟠 建议 |
| 线缆应力释放 | 格兰头压紧线束；盒内留余量，外力不直接拽端子 | 🔴 必做 |
| 冷压端子 | 线头压 OT/管型端子再进端子排，勿裸铜丝夹螺丝（短路风险源） | 🔴 必做 |

## 4. 固件可靠性

| 项 | 做法 | 状态 |
|---|---|---|
| **看门狗 WDT** | ESP32 硬件看门狗（卡死自动复位）；当前固件未启用，需加 | 🟠 待加 |
| 掉电恢复 | 已验证：重启全部继电器关闭 + NVS 配置保留（确认 main.cpp begin 顺序） | ✅ |
| 故障自恢复 | 干转/超时/日限额 → 自动停泵关阀；Web/屏幕可恢复 | ✅ |

## 5. 电磁兼容（结合 UART 乱码教训）

- 12V/5V 电源线与 I2C/湿度计模拟线**分两侧线槽走**，避免并行过长
- 湿度计 AO 用双绞线对（网线芯对），1-3m 内信号干净
- 继电器/泵的 12V 线不与信号线同束
- 若 UART 乱码重现：12V 线远离 FT232R/串口线，必要时给 12V 线加磁环

## 6. 接线规范红线（教训固化）

| 规则 | 说明 |
|---|---|
| NC 端子**悬空不接** | 接 GND = 12V 短路（曾烧 470Ω） |
| 继电器 VCC 按线圈电压 | 3.3V 模块接 3.3V；5V/12V 线圈模块与 3.3V MCU 不兼容 |
| 12V 只走触点侧 | COM/NO/NC，绝不进 VCC/IN/信号端子 |
| 上电前测短路 | 万用表 12V+ 对 GND 应开路/几十 kΩ 以上，0Ω 禁止上电 |
| 共地 | 12V GND / 5V GND / ESP32 GND 一条线 |

## 7. 装机自检顺序

1. 裸板（盒外）：全部功能测通（泵/阀/湿度/Web/屏幕）
2. 盒内布装：发热件固定、线束走位、格兰头锁紧
3. 刷三防漆 + 干燥剂 + 透气阀
4. **上电前**：万用表 12V+↔GND 无短路 → 保险丝在 → 续流二极管极性对
5. 上电 → 全功能复测 → 密闭盒温升观察（1 小时）→ 淋水/高湿环境测试

*装机中任何异常（异味/发热/异响）立即断电排查；本清单与 engineering-wiring.md 配套使用。*
