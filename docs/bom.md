## 电磁阀选型（重要）

| 项目 | 要求 | 常见错误 |
|------|------|----------|
| 类型 | **两通（2-way）** 一进一出 | 误买 **三通（3-way）** 切换阀 |
| 常态 | **常闭 NC**（断电关、通电开） | 买成常开 NO |
| 电压 | **12 V DC** | 与交流 220 V 阀混用 |
| 口径 | G1/2"（4 分）或 G1/4"（2 分），与 YF-S201、软管一致 | 口径不一致大量漏水 |
| 材质 | 淡水：黄铜 / 塑料体均可 | — |
| 数量 | **1 盆 = 1 阀** | — |

搜索关键词：`12V 常闭 电磁阀 两通 水阀 G1/2`、`12V NC solenoid valve 2 way`.

## ⚠️ 继电器选型红线（2026-08-18 实测踩坑，务必遵守）

> 3.3V MCU（ESP32-S3 / C3）**不能直接驱动 5V 或 12V 线圈的光耦继电器模块**。3.3V
> 电平对 5V/12V 模块是"非法电平"：高电平档吸合无力（触点虚接、NO 无输出），低电平档
> 误吸合（IN=3.3V 半导通、灯亮关不掉）。实测：SRD-12VDC 接 5V VCC 时"灯亮但无咔嗒"。

| 要求 | 说明 |
|------|------|
| 线圈电压 | **SRD-03VDC（3V）** 或模块标注"3.3V 驱动 / 3.3V-5V 兼容" |
| 触发方式 | **低电平触发**（IN 接地吸合）——与固件"高阻关断 + 0V 吸合"匹配 |
| 供电 | VCC 按线圈电压接（3.3V 模块接 3.3V）；**12V 只走触点侧 COM/NO/NC** |
| 触点 | ≥10 A / 250 VAC；泵/阀电流远小于此，留余量 |
| 采购话术 | 下单前必问卖家：**"ESP32 3.3V 电平、低电平触发，能直接驱动吗？"** |

**接线错误警示**：NC 端误接 GND 会把 12V 轨直接短路（曾导致电源板 470Ω 电阻冒烟烧毁）——
**NC 端子悬空不接**，负载只接 NO。
